# Restate Technical SDR/BDR Portfolio

A practical technical sales development portfolio demonstrating how I research a developer-infrastructure product, define its ICP, select and investigate a target account, translate a technical workflow into a business hypothesis, map the buying committee, and build coordinated outbound.

## Portfolio focus

- **Vendor researched:** Restate
- **Category:** Durable execution / workflow infrastructure
- **Target account exercise:** Ramp
- **Account context:** Ramp Stack and accounting workflow automation
- **Target audience:** Engineering, platform, distributed-systems, and AI infrastructure leaders
- **Purpose:** Demonstrate technical fluency, account research, buyer understanding, and outbound execution—not claim access to a prospect's internal systems.

## How to read this portfolio

1. Start with product intelligence to understand the product category and what Restate does.
2. Review the ICP and vendor research to see how a target account is selected.
3. Read the Ramp dossier and evidence register before the technical pain hypothesis.
4. Review buyer intelligence before the outbound messages.
5. Finish with the sequence and coordination plan.

## Research integrity

This is an independent portfolio exercise based on public information and explicit hypotheses. It does **not** claim that Ramp uses a particular queue, database, orchestration framework, or internal architecture. References to possible retries, timeouts, duplicate side effects, or operational complexity are scenario-based discovery hypotheses—not statements of known incidents at Ramp.

Product capabilities are described at a category level and should be revalidated against current Restate documentation before use in a live sales conversation. Restate does not by itself guarantee exactly-once effects in arbitrary external systems. Application-level idempotency, deduplication, and reconciliation remain important for external side effects.

## Scope

This repository intentionally excludes the technical demo / proof-of-concept implementation. It contains the research, reasoning, messaging, and campaign artifacts leading up to that stage.
